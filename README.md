# xpmi-tools

Shared Odoo 19 addons maintained by XPMI, organized in an OCA-like repository layout.

| --------- | ---------- | -------------------------------------------------------------------------------------------------- |
| xpmi_riba | 19.0.1.0.0 | This module sets the payment date if it is a bank riba with the due date calculated in the invoice |

## Repository scope

- Import and migration helpers for partners, products, and sales orders.
- Italian localization/report adjustments (DDT and EDI behaviors).
- Customer invoice report customizations for accounting workflows.
